3D-модель рельефа: турбаза в долине ручья (Байкальский хребет)

Задача
Создать 3D-визуализацию рельефа с инфраструктурой для оценки территории под размещение турбазы в предгорье Байкальского хребта.

Данные
DEM: SRTM 30m (OpenTopography).

Инфраструктура: OpenStreetMap (ручей, тропы)

Границы участка: условный полигон (~5×6 км).

Инструменты
QGIS 3.44

QuickOSM

Warp (Reproject) → EPSG:32648

Qgis2threejs (экспорт в HTML)

Print Layout / скриншоты
